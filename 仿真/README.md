# 无背景光直方图反演与仿真对比

本目录以同一流程处理无背景光3%和88%两个文件的前100条记录（数据行索引0至99）：逐条反演每周期每bin的平均入射光子数，再按bin对100条反演结果取平均；以平均入射光子谱为输入，生成100条新的随机探测直方图，并与相应实测谱比较。第1至7节保留3%案例的参数、公式及结果，88%案例的结果见第8节。

原始MATLAB算法保留在[反演算法/spad_hist_inverse.m](反演算法/spad_hist_inverse.m)，Python模型为[反演算法/spad_hist_inverse.py](反演算法/spad_hist_inverse.py)，执行入口为[compare_inverse_simulation.py](仿真数据与实际数据的对比/compare_inverse_simulation.py)。

## 1 参数与数据口径

| 参数 | 本次使用值 |
| --- | --- |
| 实测文件 | 无背景光3%文件 |
| 使用记录 | 前100条，索引0至99，不含CSV表头 |
| 每条累计周期数N | 40000，取自文件名 |
| 死时间D | 120 bin，已确认采用理论文档设置 |
| 最低可信可用概率 | 0.02，与MATLAB默认值一致 |
| 条件触发概率上限 | 严格小于`1 - 1e-6`，与MATLAB一致 |
| 仿真条数 | 100，每条同为40000周期 |
| 随机种子 | 20261110 |
| 基线SNR阈值 | 8 |

全部2048个bin进入反演和仿真，保留窗口之前的死时间历史；不裁剪、对齐、平滑或归一化实测谱，不按SNR先筛掉输入记录。前100条的原始POS均为500；峰值bin在55至62之间。特征比较阶段另行调用现有基线并执行SNR有效性判断。

“无背景光”按所选数据文件分组，不额外扣除暗计数或其他杂散计数。反演得到的是在所用探测模型和参数下能够解释全部观测计数的平均输入谱，不是独立测得的真实光子数。

## 2 逐条反演

令第$k$条实测直方图为$H_i^{(k)}$。按原MATLAB算法，采用单SPAD、非瘫痪死时间和每周期开始可用的模型：

$$
p_i^{(k)}=\frac{H_i^{(k)}}{N},\qquad
A_i^{(k)}=1-\sum_{j=\max(0,i-D)}^{i-1}p_j^{(k)}.
$$

反演为

$$
\hat\lambda_i^{(k)}
=-\ln\left(1-\frac{p_i^{(k)}}{A_i^{(k)}}\right).
$$

当$A_i^{(k)}<0.02$，或条件概率不满足$0\le p_i^{(k)}/A_i^{(k)}<1-10^{-6}$时，该bin及后续所有bin均保持NaN，遵循MATLAB的停止反演规则。程序不会用`nanmean`静默排除这些位置；若前100条中出现不可信反演，将报告并停止本次平均输入仿真。

本次全部100×2048个bin均可反演，最低可用概率为0.955525。Python诊断的bin编号从0开始；原MATLAB数组位置从1开始。Python另外按无死时间物理极限处理`dead_bins=0`，当前D=120的流程与所给MATLAB算法规则一致，原MATLAB文件未作修改。

## 3 先反演再平均

每个bin按以下顺序求平均：

$$
\bar\lambda_i=\frac1{100}\sum_{k=1}^{100}\hat\lambda_i^{(k)}.
$$

$\bar\lambda_i$的单位是光子/周期/bin。全窗每周期平均光子数与每条40000周期对应的平均入射光子数分别为

$$
\bar\Lambda=\sum_i\bar\lambda_i,\qquad
\bar N_{ph}=N\bar\Lambda.
$$

本次结果为

$$
\bar\Lambda=0.04474751975318195,\qquad
\bar N_{ph}=1789.900790127278.
$$

保留平均谱的形状作为仿真输入，不只用总光子数重新拟合高斯模板。非线性反演下，“先反演再平均”通常不同于“先平均直方图再反演”；本次严格采用前者。

## 4 确定性前向与随机仿真

平均输入对应的探测概率由同一模型递推：

$$
\bar A_i=1-\sum_{j=\max(0,i-D)}^{i-1}\tilde p_j,\qquad
\tilde p_i=\bar A_i(1-e^{-\bar\lambda_i}),\qquad
H_i^{expected}=N\tilde p_i.
$$

这里的$\bar A_i$根据平均输入的前向探测概率重新计算，不直接复用某条实测谱的可用概率。

随机仿真对每条新直方图、每个bin计算当前可用周期数

$$
n_i^{available}=N-\sum_{j=\max(0,i-D)}^{i-1}H_j^{sim},
$$

随后抽取

$$
H_i^{sim}\mid\text{history}
\sim\operatorname{Binomial}\left(n_i^{available},1-e^{-\bar\lambda_i}\right).
$$

在独立Poisson入射、固定输入谱、非瘫痪和逐周期复位的假设下，这种聚合抽样保留了周期内死时间约束。过去D个bin内的探测来自互不重叠的周期集合，其计数之和就是当前不可用周期数，因此可用周期的当前触发计数服从上述二项分布。这样无需显式分配40000×2048的事件矩阵，也不是对每个bin独立抽取Poisson观测计数。

## 5 对比结果

两批数据都通过现有基线计算csum、ctd、完整va和snr，保留30-bin候选窗口、扣背景截零及SNR≥8的规则。以下为逐帧特征的均值，不是先平均直方图再提取特征。

| 指标 | 实测均值 | 仿真均值 |
| --- | ---: | ---: |
| 全窗总探测计数 | 1753.640000 | 1756.130000 |
| csum | 1639.570000 | 1641.050000 |
| ctd，bin编号中心坐标 | 58.421266 | 58.398792 |
| 完整va，bin | 3.747913 | 3.758747 |
| snr | 40.488812 | 40.505858 |
| 有效峰数 | 100/100 | 100/100 |

实测平均探测总数和仿真平均探测总数相差约0.1420%。平均谱之间的主要误差指标采用均方根误差：

$$
RMSE_W=\sqrt{\frac1{|W|}\sum_{i\in W}
(\bar H_i^{sim}-\bar H_i^{real})^2}.
$$

主指标使用实测平均谱峰值附近的30-bin共同窗口，本次为`[44,74)`，即bin 44至73。全谱2048个bin的RMSE作为辅助指标。两者单位均为每条直方图的计数；保持相同累计周期数，不先归一化计数。

| 比较对象 | 主峰30-bin窗口RMSE | 全谱RMSE |
| --- | ---: | ---: |
| 随机仿真均值 vs 实测均值 | 0.666408283 | 0.084697013 |
| 平均输入的确定性前向期望 vs 实测均值 | 0.001092755 | 0.000133059 |

全谱中大量零计数或低计数bin会稀释主峰误差，因此以主峰窗口RMSE为主。随机仿真与实测两批序列独立，应比较各自平均谱；同号帧并非同一次噪声实现，不将逐帧相减的RMSE解释为预测误差。RMSE描述当前计数曲线的差异，不能单独代表质心精度或独立物理模型有效性。

相对L1作为补充记录：随机仿真平均谱为2.192582%，平均输入确定性前向谱为0.001666%。其定义为$\sum_i|\hat H_i-\bar H_i|/\sum_i\bar H_i$，包含全2048个bin。

逐条反演再逐条前向的最大计数差约为`5.68e-14`，这是代数回代一致性，不是独立的物理模型验证。平均输入仿真与实测均值仍有随机抽样差异，也未刻意令每个仿真bin的均值等于实测均值。

完整帧间标准差、残差和诊断参数见[结果说明](仿真数据与实际数据的对比/对比结果/输出_03%/结果说明.md)和[summary.json](仿真数据与实际数据的对比/对比结果/输出_03%/summary.json)。同一批实测用于反演和比较，因此本次是同数据一致性及随机重复性检查；固定平均输入的仿真没有另外加入实测帧间强度漂移或时延漂移。

## 7 运行与测试

## 9 仿真与实测一致性及可靠性结论

在无背景光3%与88%两个工况下，分别使用前100条实测直方图逐条反演并求平均输入，按照每条40000周期、120-bin非瘫痪死时间和逐周期复位的设置生成100条随机仿真谱。仿真与实测采用同一套基线和统计窗口，得到以下比较结果：

| 一致性指标 | 无背景光3% | 无背景光88% |
| --- | ---: | ---: |
| 平均总探测计数相对差 | 0.141990% | 0.023595% |
| 平均谱主峰30-bin窗口RMSE，计数 | 0.666408283 | 2.007114014 |
| 平均谱全2048-bin RMSE，计数 | 0.084697013 | 0.247782352 |
| ctd均值绝对差，bin | 0.022473349 | 0.012080417 |
| 完整va均值绝对差，bin | 0.010833355 | 0.005089386 |
| 有效峰数量，实测与仿真 | 均为100/100 | 均为100/100 |

两个工况下的平均总探测计数相对差均小于0.15%，ctd均值绝对差均小于0.023 bin，完整va均值绝对差均小于0.011 bin，平均主峰曲线也具有较小的计数RMSE。这些数值用于描述本次结果，并不是预先设定的通用验收阈值。两组入射光强不同，直接比较绝对计数RMSE不能据此判断哪个工况的模型更准确。

本次对比表明：**在所测试的无背景光3%和88%工况、40000周期及120-bin死时间设置下，仿真数据与实测数据在平均直方图形状、平均探测计数、ctd均值和完整va均值方面具有较好的一致性，说明所实现的反演—前向仿真流程在复现当前样本平均回波响应方面是可靠的，可作为这些条件下后续算法研究的仿真基础。**

这里的可靠性结论针对当前样本及参数下的平均响应复现。仿真输入由参与比较的同一批实测数据反演得到，提供的是同数据一致性和实现正确性的证据，尚未构成独立的预测验证。帧间统计也并非完全一致：3%数据的ctd标准差实测为0.153492 bin、仿真为0.125753 bin，88%分别为0.086254 bin和0.050980 bin。因此，本结论不扩展为所有随机波动、独立新数据、有背景光或饱和工况均已验证可靠；这些情形需要额外验证。
