# 仿真直方图查看器

桌面GUI用于浏览[数据集](../数据集/README.md)已保存的直方图及特征。选择质心、信号lambda、背景lambda和帧号，即可查看全谱、主峰局部图，以及ctd、完整va、csum、snr、sa_avg的**当前帧值和同组合100帧平均值**。

## 数据是否来自实测反演

是。信号模板来自无背景光3%实测数据的前100条：每条按实测累计40000周期反演，按bin求均值，保留主峰附近30-bin窗口`[44,74)`（原数据0起始索引），再归一化。模板平移到各目标质心后，以`lambda[i] = signal_lambda * q[i] + background_lambda`为前向模型输入，生成每条累计5000周期的随机探测直方图。它们是基于实测反演模板的新仿真记录，不是直接复制的实测直方图。主峰窗口外的实测尾部不作为信号模板，背景按配置的lambda单独叠加。

## 启动

当前电脑可直接双击同目录的`启动查看器.bat`，优先使用`D:\Software\anaconda\envs\1dcnn\pythonw.exe`。其他电脑可在安装NumPy、Matplotlib及Tk的Python环境中运行：

```powershell
python -X utf8 "仿真/查看器/histogram_viewer.py"
```

支持`--dataset`指定另一份同格式数据集，也可在界面点击“打开数据集目录”。默认目录为`仿真/数据集`，无论从哪个工作目录启动都能找到。

## 使用

- 质心、信号和背景选项从数据文件读取，默认支持当前7个质心、10档信号lambda、6档背景lambda。
- 帧号采用1至100；界面底部同时注明对应的0起始数组索引。可直接输入帧号、使用上下箭头或“上一帧/下一帧”；快捷键为Ctrl+左/右。
- 上图为2048-bin全谱，下图显示输入信号质心附近的局部区域。虚线标出有效ctd，点线标出实际输入信号质心，浅色区域为观测最大峰的分析窗口，水平线为该条记录的sa_avg。
- 勾选“叠加模型期望”可查看相同参数下的确定性前向期望；这是模型期望，不是另一条随机记录。
- 绘图工具栏支持平移、缩放、恢复视图和保存图片。
- 右侧五项特征并排显示“当前帧”和“100帧均值”。当前值直接读取该帧的已保存特征；平均值针对同一质心、同一信号lambda和背景lambda下的全部100帧，分别对每项特征的有限值求算术均值，同时显示有效帧数。仅切换帧号不会改变均值，切换质心或任一种lambda会更新均值。这是逐帧特征的平均，不是先平均直方图再计算特征。
- csum不严格大于20或SNR低于8时，ctd/va显示“无有效值”，不会用0或理想质心补齐；其他能够计算的指标仍显示。数据状态会区分`low_csum`和`low_snr`。100帧中某项全部无效时，其平均值也显示“无有效值”，有效帧数为0/100。csum、snr、sa_avg即使未通过有效峰门限仍会显示。
- 界面同时显示全谱探测计数、观测最大bin、实际输入质心、理想信号va、累计周期、死时间、csum/SNR门限和失败原因。

信号lambda是整条信号谱每周期的平均入射光子数；背景lambda是每bin每周期的平均入射背景光子数。sa_avg是从该条探测直方图估计的背景计数/bin，不等同于输入background_lambda。

查看器只读数据。切换质心时后台解压一个质心的数据，完成后在内存中切换信号、背景和帧；不会重新生成随机数据，也不会修改数据集。所有bin和ctd显示1起始坐标，va单位为bin。

## 检查

```powershell
python -X utf8 -m unittest discover -s "仿真/直方图查看器" -p "test_*.py" -v
python -X utf8 "仿真/查看器/gui_smoke_test.py"
```

界面自检会打开窗口，检查无效/有效帧、指标显示、绘图数据、模型期望叠加和质心切换，保存`gui_preview.png`后自动关闭。
